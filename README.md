# 👋 Welcome!

## 🧛‍♂️ About me
I'm **Vivien**, a **full-stack JavaScript / TypeScript developer** based in France. I build web apps with **Vue/Nuxt** and **NestJS**, from the interface all the way to production.  
What I care about: polished interfaces, reliable apps, and the people who use them every day.

I switched careers in 2021, earned a **French state-certified web developer degree (RNCP level 5)** through OpenClassrooms, and I've been coding with passion ever since!

## 🚀 Experience

### 🩺 Neuralix — Full-Stack Developer · *since April 2025*
Medical applications built with **Angular, NestJS and PostgreSQL**, used by **2,000+ psychomotor therapists across 4 countries**.
- Built apps used to assess **~50,000 patients** with the NP-MOT
- Automated paper test collection and scoring, saving practitioners **1h30 per patient**
- Centralized business rules on the server and wrote **automated tests** for critical features
- Contributed to architecture decisions and specifications

### 🍽️ SpinforEat — Front-End Developer · *Aug 2022 → Dec 2023*
- Built **2 Vue 3 apps** for QR-code loyalty, point tracking and rewards
- Designed a **Nuxt showcase website** for a restaurant, with a focus on accessibility and SEO
- Integrated the internal API alongside the back-end team

## 🐝 Side project: [Manga Hive](https://www.manga-hive.com/)
A **free, ad-free** platform to manage your manga collection, track your reading and never miss a French release.  
Designed, built and maintained solo, from data scraping all the way to the mobile app stores:
- 🌐 **Web**: Nuxt (SSG for the landing site, SPA for the app), Pinia, Tailwind
- 📱 **Mobile**: React Native with Expo, available on [Google Play](https://play.google.com/store/apps/details?id=com.mangahive.mobile) and the App Store
- ⚙️ **Backend**: NestJS, Prisma, PostgreSQL, Redis, BullMQ
- 🗂️ **Data**: a custom API powered by my own catalog of French manga and editions
- ☁️ **Infra**: Docker, Coolify on a VPS, Cloudflare R2, Sharp for image processing

👉 More details on [my portfolio](https://vivieng.com/en/project/manga-hive)
